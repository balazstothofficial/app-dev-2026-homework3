# App Development 2026 — Homework 3

Build a **Shop App** with Jetpack Compose.

## Getting started

1. Clone your personal assignment repository created by Classmoji.
2. Open the repository in Android Studio.
3. Open `app/src/main/java/tcs/app/dev/homework1/ShopScreen.kt` for the tasks.
4. Run the app on an emulator or Android device.

The `data` package provides the shop model. Implement the shopping UI yourself.
`MainActivity` already opens this homework's screen.

## Reference material

The `exercise` package contains the Compose exercises and their solutions.
The testing exercises are in `app/src/test/` and `app/src/androidTest/`.
After homework solutions are released, find them in `homework1/solution/`,
including an animated version. To run one, change the `ShopScreen` import in
`MainActivity` to the solution's package.
